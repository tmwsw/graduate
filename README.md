# 🛠 РемонтТех — информационная система управления ремонтами компьютеров

Проект представляет собой веб-приложение, созданное для автоматизации работы сервисного центра по ремонту компьютерной и электронной техники.  
Система позволяет централизованно управлять клиентами, устройствами, мастерами и заявками, а также предоставляет инструменты для анализа и контроля выполняемых работ.

Разработано в рамках выпускной квалификационной работы студентом ГБПОУ МО «Физтех-колледж».

---

## 📋 Основные возможности

- 👥 **Клиенты** – добавление, редактирование, удаление и просмотр информации о заказчиках  
- 💻 **Устройства** – регистрация техники с привязкой к конкретному клиенту  
- 👨‍🔧 **Мастера** – учёт специалистов, их специализации, загрузки и статуса  
- 📦 **Заявки на ремонт** – полный цикл обработки: создание, изменение статусов, назначение мастера, расчёт стоимости  
- 🔐 **Аутентификация и роли** – вход в систему с разделением прав доступа (администратор, менеджер, мастер)  
- 🔍 **Поиск и фильтрация** – быстрый поиск заявок, клиентов, устройств по различным параметрам  
- 📊 **Аналитика** – визуализация статистики на главной панели: круговая и линейная диаграммы, сводные показатели  

---

## 🧱 Архитектура

Система построена по **клиент-серверной архитектуре** и состоит из двух независимых частей:

### 🔹 Бэкенд (серверная часть)

- Язык: **Python 3.12+**
- Веб-фреймворк: **FastAPI**
- ORM: **SQLAlchemy**
- База данных: **SQLite**
- Взаимодействие: **REST API**, обмен данными в формате JSON
- Авторизация: проверка логина/пароля с хешированием, хранение сессии на клиенте

### 🔹 Фронтенд (клиентская часть)

- **HTML5, CSS3, JavaScript (ES6+)**
- CSS-фреймворк: **Bootstrap 5**
- Диаграммы: **Chart.js**
- Сборка: не требуется (нативный JS, модули)
- Запуск: через **Live Server** (VS Code) или любой статический сервер

---

## 🗄 Структура базы данных

Основные таблицы:

- `clients` – клиенты сервисного центра  
- `devices` – устройства, привязанные к клиентам  
- `masters` – мастера  
- `orders` – заявки на ремонт  
- `users` – пользователи системы (администраторы, менеджеры, мастера)  

Связи между таблицами обеспечиваются внешними ключами, что гарантирует целостность данных.

## 🚀 Запуск проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-repo/remonttech.git
cd remonttech
Если вы не используете Git, просто скачайте и распакуйте архив с проектом.
```

### 2. Установка зависимостей (Python)

```bash
python -m venv venv
venv\Scripts\activate   # Windows
source venv/bin/activate   # Linux / macOS
```
Установите необходимые пакеты:

```bash
pip install -r requirements.txt
```
### Состав requirements.txt:
- fastapi
- uvicorn[standard]
- sqlalchemy
- pydantic
- passlib[bcrypt]

### 3. Запуск бэкенда
Из корневой папки проекта выполните:
```bash
uvicorn python.main:app --reload --host 127.0.0.1 --port 8000
```
Сервер запустится на:
http://127.0.0.1:8000

Интерактивная документация API:
http://127.0.0.1:8000/docs

### 4. Запуск фронтенда
Откройте папку с HTML-файлами с помощью Live Server в VS Code или настройте любой статический сервер.

По умолчанию фронтенд будет доступен на:
http://127.0.0.1:5500

⚠️ Важно: фронтенд и бэкенд работают на разных портах.
CORS уже настроен и разрешает кросс-доменные запросы.

### 5. Автоматический запуск (опционально)
Для удобства можно использовать два .bat-файла:

`start_backend.bat` – запускает сервер с проверкой, не занят ли порт
`stop_backend.bat` – останавливает сервер

Они находятся в корне проекта.
