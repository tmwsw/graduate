# 🛠 Информационная система управления ремонтами компьютеров РемонтТех

## 📌 Описание проекта

Данный проект представляет собой веб-приложение, предназначенное для автоматизации деятельности сервисного центра по ремонту компьютерной техники. Система обеспечивает удобное управление данными о клиентах, устройствах, мастерах и заявках на ремонт, а также предоставляет инструменты для контроля и анализа выполняемых работ.

Основной целью разработки является повышение эффективности работы сервисного центра за счёт цифровизации ключевых бизнес-процессов и централизованного хранения информации.

---

## 🎯 Основные возможности

Система реализует следующий функционал:

* 👥 учёт клиентов (добавление, редактирование, удаление, просмотр)
* 💻 регистрация устройств с привязкой к клиентам
* 👨‍🔧 управление мастерами с указанием специализации и статуса
* 📦 создание и обработка заявок на ремонт
* 🔄 изменение статусов заявок (новая, в работе, завершена и др.)
* 💰 учёт стоимости работ
* 🔍 поиск и фильтрация по ключевым параметрам
* 📊 отображение актуальной информации и последних заявок

---

## 🧱 Архитектура системы

Система построена по клиент-серверной архитектуре:

### 🔹 Backend

* обработка бизнес-логики
* работа с базой данных
* реализация REST API

### 🔹 Frontend

* пользовательский интерфейс
* взаимодействие с сервером через API
* визуализация данных

## 🗄 Структура базы данных

В системе реализована реляционная база данных, включающая основные сущности:

* Клиенты (clients)
* Устройства (devices)
* Мастера (masters)
* Заявки на ремонт (orders)
* Пользователи и роли (users, roles)

Связи между сущностями обеспечивают целостность данных и отражают реальные бизнес-процессы сервисного центра.

---

## 🔐 Аутентификация и роли

Система поддерживает разграничение прав доступа:

* **Администратор** — полный доступ
* **Менеджер** — управление заявками и клиентами
* **Клиент** — ограниченный доступ

Аутентификация реализована с использованием JWT-токенов.

## 🚀 Запуск проекта

1. Клонировать репозиторий:

```bash
git clone https://github.com/graduate.git
cd project
```

2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Запустить сервер:

```bash
uvicorn main:app --reload
```

4. Открыть в браузере:

```
http://127.0.0.1:8000
```
